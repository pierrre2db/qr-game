# Guide du Joueur - QR Game CEFOR

Bienvenue dans le QR Game CEFOR ! Ce guide vous explique comment participer à cette chasse au trésor interactive basée sur des QR codes.

## Comment jouer

### 1. Préparation

Pour participer au jeu, vous aurez besoin :
- D'un smartphone avec un navigateur web
- D'un accès à la caméra de votre appareil
- D'une connexion internet (au moins au début du jeu)

### 2. Accéder au jeu

1. Scannez le QR code principal ou accédez à l'URL du jeu
2. L'application s'ouvrira dans votre navigateur
3. Vous pouvez également installer l'application sur votre écran d'accueil (c'est une PWA)

### 3. Inscription

1. Sur l'écran d'accueil, entrez votre nom
2. Cliquez sur "Commencer le jeu"
3. Autorisez l'accès à la caméra lorsque demandé

### 4. Parcours de jeu

#### Navigation libre

Le jeu est conçu pour être exploré librement :
- Vous pouvez scanner les QR codes dans n'importe quel ordre
- Chaque QR code correspond à une question différente
- Vous ne pouvez répondre qu'une seule fois à chaque question

#### Scanner un QR code

1. Pointez la caméra de votre appareil vers un QR code
2. Maintenez l'appareil stable jusqu'à ce que le QR code soit reconnu
3. La question correspondante s'affichera automatiquement

#### Répondre aux questions

Selon le type de question, vous pourrez :
- Sélectionner une option parmi plusieurs choix
- Saisir une réponse textuelle
- Entrer une valeur numérique
- Laisser un commentaire

Après avoir répondu :
1. Cliquez sur "Soumettre"
2. Vous verrez immédiatement si votre réponse est correcte
3. Cliquez sur "Continuer" pour revenir au scanner de QR code

#### Suivre votre progression

- Une barre de progression en haut de l'écran indique combien de questions vous avez répondues
- Le nombre total de questions dépend de l'événement auquel vous participez
- Vous pouvez voir votre score actuel à tout moment

### 5. Écran de fin

Une fois que vous avez répondu à toutes les questions :
1. Un écran récapitulatif s'affichera
2. Vous verrez toutes vos réponses et votre score total
3. Vous pourrez voir quelles réponses étaient correctes ou incorrectes

## Astuces et conseils

### Pour un scan optimal

- Assurez-vous que l'éclairage est suffisant
- Évitez les reflets sur le QR code
- Tenez votre appareil à environ 15-20 cm du QR code
- Gardez l'appareil stable pendant le scan

### Gestion de la progression

- Votre progression est automatiquement sauvegardée
- Vous pouvez quitter l'application et y revenir plus tard sans perdre vos réponses
- Si vous changez d'appareil, vous devrez recommencer depuis le début

### Problèmes courants

| Problème | Solution |
|----------|----------|
| La caméra ne s'active pas | Vérifiez que vous avez accordé les permissions nécessaires |
| Le QR code n'est pas reconnu | Améliorez l'éclairage ou rapprochez-vous du code |
| Message "Déjà répondu" | Vous avez déjà répondu à cette question, cherchez un autre QR code |
| L'application se fige | Rafraîchissez la page et réessayez |

## Règles du jeu

1. Répondez à toutes les questions pour compléter le jeu
2. Chaque question ne peut être répondue qu'une seule fois
3. Les points sont attribués en fonction de la difficulté des questions
4. Le joueur avec le score le plus élevé à la fin de l'événement sera déclaré gagnant
5. En cas d'égalité, le temps total sera pris en compte

## Bonne chance !

Explorez, découvrez et amusez-vous ! Le QR Game CEFOR est conçu pour vous faire découvrir le Centre de Formation CEFOR et la gastronomie de manière ludique et interactive.

Si vous rencontrez des difficultés, n'hésitez pas à demander de l'aide à un organisateur.
