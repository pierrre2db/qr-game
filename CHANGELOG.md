# Changelog

Toutes les modifications notables apportées à ce projet seront documentées dans ce fichier.

Le format est basé sur [Keep a Changelog](https://keepachangelog.com/fr/1.0.0/),
et ce projet adhère au [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-04-27

### Ajouté
- Interface d'administration complète (tableau de bord, gestion des questions, QR codes, paramètres)
- Fonctionnalité de réinitialisation des statistiques avec protection par mot de passe
- Système de sauvegarde et restauration des données
- Tests fonctionnels et d'intégrité des données
- Plan de test complet pour l'interface d'administration
- Documentation utilisateur détaillée (GUIDE-UTILISATEUR.md)

### Modifié
- Refonte de l'interface d'administration pour une meilleure ergonomie
- Amélioration de la génération des QR codes avec options de personnalisation
- Mise à jour du README avec toutes les fonctionnalités actuelles

### Corrigé
- Problèmes de navigation entre les interfaces d'administration
- Validation des données lors de l'import/export
- Gestion des erreurs dans les API

## [0.2.0] - 2025-04-15

### Ajouté
- Fonctionnalité de scan de QR codes
- Support des liens profonds vers des questions spécifiques
- Interface de jeu responsive
- Stockage local pour la progression du jeu

### Modifié
- Amélioration de l'interface utilisateur
- Optimisation des performances

## [0.1.0] - 2025-04-01

### Ajouté
- Structure initiale du projet
- API REST de base pour les questions et réponses
- Interface de jeu basique
- Stockage des données dans des fichiers JSON
