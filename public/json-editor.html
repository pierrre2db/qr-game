Structure JSON requise

Le fichier JSON doit avoir la structure suivante :

{
  "questions": [
    {
      "id": "Q1",
      "title": "Titre de la question",
      "description": "Description de la question",
      "type": "standard",
      "points": 10,
      "order": 1,
      "options": ["Option 1", "Option 2", "Option 3", "Option 4"],
      "correctAnswer": "Option 1"
    },
    {
      "id": "Q2",
      "title": "Question subsidiaire",
      "description": "Combien de personnes ont participé?",
      "type": "number",
      "points": 20,
      "order": 2,
      "minValue": 0,
      "maxValue": 1000,
      "correctAnswer": "342"
    },
    {
      "id": "Q3",
      "title": "Commentaire final",
      "description": "Vos impressions sur le jeu",
      "type": "comment",
      "order": 3,
      "isEndGame": true,
      "points": 0
    }
  ]
}
Types de questions disponibles :
  • standard : Question à choix multiples avec options
  • text : Question à réponse libre textuelle
  • number : Question numérique (ex: question subsidiaire)
  • comment : Champ de commentaire (souvent utilisé en fin de jeu)
Champs requis :
  • id : Identifiant unique de la question
  • title : Titre court de la question
  • description : Texte complet de la question
Champs optionnels :
  • type : Type de question (standard, text, etc.)
  • points : Nombre de points pour cette question
  • order : Ordre d'affichage
  • options : Tableau des options de réponse
  • correctAnswer : Réponse correcte
